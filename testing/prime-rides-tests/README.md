# Prime Rides UI and API Automation

Maven test project using Selenium WebDriver, Chrome, and TestNG. Selenium Manager selects a compatible ChromeDriver.

## Requirements

- Java 17 or newer
- Maven 3.8 or newer
- Google Chrome
- Prime Rides frontend at `http://localhost:5174`
- Backend and PostgreSQL running for API and vehicle catalog cases

## Run the complete suite on Windows

Start the backend and frontend in separate terminals and keep them running. In a third terminal:

```powershell
cd C:\Users\neeha\Downloads\PRIME-RIDES\testing\prime-rides-tests
& "C:\Tools\apache-maven-3.10.0\bin\mvn.cmd" clean test -DbaseUrl=http://localhost:5174
```

Run Chrome visibly, or override the frontend port:

```powershell
& "C:\Tools\apache-maven-3.10.0\bin\mvn.cmd" clean test -DbaseUrl=http://localhost:5174 -Dheadless=false
```

The suite contains 186 individual TestNG invocations across navigation, form boundaries, API validation, responsive layout, vehicle filtering, images, and booking entry. Vehicle catalog and booking UI cases are skipped when the database has no available vehicles; API failures are reported as failures. Negative API cases do not create accounts or bookings.

## Results

Every run writes:

- Visual dashboard: `target/prime-rides-test-report.html`
- Detailed TestNG results: `target/surefire-reports/`

Open the dashboard from this directory with:

```powershell
ii .\target\prime-rides-test-report.html
```

The dashboard shows real passed, failed, and skipped counts, a chart, and expandable per-case details with failure messages. It is regenerated by each run.
